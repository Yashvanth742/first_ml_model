This project focuses on predicting the aqueous solubility (logS) of molecules using machine learning techniques. A dataset containing molecular descriptors was loaded and preprocessed by separating features and target variables. The data was split into training and testing sets, and two regression algorithms—Linear Regression and Random Forest Regression—were trained on the dataset. Model performance was evaluated using Mean Squared Error (MSE) and R² Score. A comparison of both models showed that Linear Regression provided slightly better prediction accuracy. Finally, data visualization techniques were used to compare actual and predicted values, helping to assess the effectiveness of the model.
